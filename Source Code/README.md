
# SmartBite Android App

## Overview

SmartBite is an Android mobile application prototype designed to help users discover recipes, save meals, and explore food ideas through a simple mobile interface.

This repository contains the Android app implementation of SmartBite. It may later be combined with other SmartBite project components such as documentation, web interface, presentation, and project management files.

## Features

- Home Screen
- Discover Recipes Screen
- Camera Screen
- Saved Recipes Screen
- Profile Screen
- Bottom Navigation
- Recipe UI Components
- API Integration Concept

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- MVVM Architecture
- Retrofit
- Navigation Component

## Project Structure

- `app/` contains the Android application source code.
- `gradle/` contains Gradle wrapper files.
- `build.gradle.kts` contains project build configuration.
- `settings.gradle.kts` contains project settings.
