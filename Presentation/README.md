
# Presentation

This folder contains the SmartBite project presentation used to demonstrate the software engineering analysis, requirements engineering, system design, and project outcomes.

## Contents

- Problem Statement
- Stakeholder Analysis
- Use Case Model
- Domain Model
- Functional Requirements
- Non-Functional Requirements
- Storyboard and User Interface Design
- Change Request Analysis
- Project Conclusion

## Description

The presentation provides an overview of the SmartBite project and summarizes the key software engineering deliverables produced throughout the project lifecycle.

It highlights the system requirements, stakeholder needs, system models, design decisions, and proposed solution for helping users generate recipes using available ingredients through AI-powered recommendations.

The presentation was created to communicate the project's objectives, analysis, design, and expected impact to instructors, evaluators, and stakeholders.
