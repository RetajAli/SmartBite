# Documentation

This folder contains the software engineering and project management documentation for the SmartBite project.

## Contents

- Vision and Scope Document
- Software Requirements Specification (SRS)
- Requirements Elicitation Report
- Traceability Matrix (RTM)
- Jira Waterfall Model Report
- Jira V-Model Report

## Description

The documents in this folder were developed during the requirements engineering, analysis, planning, and project management phases of the SmartBite project.

They define the project vision, business objectives, stakeholder requirements, functional and non-functional requirements, use cases, requirement traceability, and project management activities performed using Jira.

These artifacts provide a complete view of the software development lifecycle from requirements gathering through planning, validation, and project execution.
