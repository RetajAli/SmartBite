
# Diagrams

This folder contains the software engineering diagrams and modeling artifacts developed for the SmartBite project.

## Contents

- Use Case Diagram
- Context Diagram
- Feature Tree
- Activity Diagram
- Sequence Diagram
- Class Diagram
- Success Metrics Diagram

## Description

These diagrams were created during the analysis and design phases of the project to model system functionality, user interactions, business requirements, system architecture, and project objectives.

The diagrams provide visual representations of the SmartBite system and support requirements engineering, software design, communication, and project documentation activities.

Both editable Draw.io files and exported PNG versions are included for reference and future modifications.
