
# Project Management Artifacts

This folder contains the Project Management deliverables developed for the SmartBite project.

## Contents

* Project Management Report
* Project Charter
* Microsoft Project Schedule
* Gantt Chart
* Work Breakdown Structure (WBS)
* Resource Planning
* Cost Estimation
* Quality Management
* Risk Management
* Project Management Presentation

## Description

These artifacts were created as part of the Project Management phase of SmartBite.

The documents demonstrate how the project was planned, scheduled, monitored, and controlled throughout its lifecycle. They include project scope definition, milestones, resource allocation, budgeting, quality planning, communication planning, and risk analysis.

Microsoft Project was used to develop the project schedule, resource sheets, and Gantt charts, while supporting documentation was prepared to justify project decisions and management strategies.
